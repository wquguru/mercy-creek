# 木头人偶马（Horse rig）+ 驿站马车挂点

由 `tools/blender/build_horse.py` 生成 `Game/Assets/_MercyCreek/Art/Characters/Horse.gltf`（浅色木）和 `Horse_B.gltf`（深一档的木色；**几何、节点、挽具完全相同，只有木纹乘色不同**，两匹马并排时不像复制粘贴）。
和人偶同一套做法：**没有蒙皮、没有骨骼**，每段是独立网格，层级就是骨架；挽具是挂在对应段下面的刚体 `Tack_*`。
一匹马约 17.2k 三角面（其中挽具 4.5k）。马车见文末。

## 导入约定
- glTFast 直接导入，**根节点不用转**。马头朝 Unity **+Z**，Y 向上，1 单位 = 1 米。Blender 里马头朝 -Y；Unity (x, y, z) = Blender (-x, z, -y)。
- 根节点 `Horse` 在地面、身体中心正下方。**L = 马自己的左边 = Unity -X**。
- 每个节点的原点在关节转轴上，**静止姿势（四腿方正站立）下所有 localRotation 都是单位旋转**；局部轴 = 马的轴：+X 马的右边，+Y 上，+Z 前。
- 肩高（鬐甲）1.60 m，躯干长 1.68 m（胸前到臀端），胸深 0.75 m（腹底离地约 0.85 m），躯干最宽 0.59 m，口鼻到尾根约 2.4 m。

## 节点
`Horse` → `Body` → `Neck` → `Head`；`Body` → `Tail`；`Body` → `FL_Upper` → `FL_Lower` → `FL_Pastern` → `FL_Hoof`（`FR_` / `HL_` / `HR_` 同）。
- 前腿：`*_Upper` = 肩关节起的上臂 + 前臂（到腕，马的"膝"），`*_Lower` = 管骨（腕 → 球节），`*_Pastern` = 系部（球节 → 蹄冠），`*_Hoof` = 蹄。
- 后腿：`*_Upper` = 髋关节起的股 + 胫（膝关节固定在里面，到跗关节），`*_Lower` = 跗关节 → 球节，`*_Pastern`、`*_Hoof` 同前。
- 挽具（深色皮 + 铁 / 铜件，原点 = 所属关节，localPosition = 0）：
  - `Body` 下：`Tack_Collar`（颈圈 + 轭木 + 挽钩，套在颈根压在肩上，**挂在 Body 不挂 Neck**——颈部转动时颈圈不动，和真的一样）、`Tack_Traces`（两侧挽绳残段，到臀后为止）、`Tack_Saddle`（背垫 + 肚带 + 缰绳圈 + 背带 + 臀带）、`Tack_Breeching`（后鞦）。
  - `Head` 下：`Tack_Bridle`（项带 / 喉革、额带、颊带、鼻革、**眼罩**、衔铁和衔铁环）。
  - 缰绳没有做进马里（它连着车夫的手，跨两个模型）。需要时从衔铁环拉到车夫手：衔铁环（马局部，Unity）左 (-0.064, 1.462, +1.439) / 右 (+0.064, 1.462, +1.439)，鞍上缰绳圈 (∓0.10, 1.66, +0.24)。
  - 挽绳残段末端（马局部，Unity）：左 (-0.335, 1.040, -0.620)，右 (+0.335, 1.040, -0.620)。马车上的挽绳正好接到这里。

## 行走（walk）：4 拍，左后 → 左前 → 右后 → 右前
`build_horse.py` 里 `walk_angles(phase)` 是参考实现，`Horse_walk.png` 是相位 0.1 的姿势（左后支撑、左前刚离地、右后摆动、右前支撑），四只蹄子都在地上或离地。
- 每条腿的相位偏移：HL 0、FL 0.25、HR 0.5、FR 0.75；支撑占比（duty factor）0.62。
- 上段支撑期从前摆匀速转到后摆；摆动期缓入缓出摆回前面，同时屈腕 / 跗关节和球节把蹄抬起。
- 支撑期的**球节角由 IK 解出**（腿斜的时候"短"，腿竖直的时候"长"，靠球节下沉补），蹄子保持水平贴地；根节点随之上下。在 32 个采样相位上量过：支撑蹄误差 0.000 m，摆动蹄最低离地 1.6 cm。

**步幅**：这个幅度下支撑期蹄子相对身体扫过 0.71 m，**步幅 = 0.71 / 0.62 ≈ 1.15 m**（前后腿一致：FL 1.143、HL 1.157）。
速度 = 步幅 × 步频。自然步频 0.9–1.0 Hz → 1.0–1.15 m/s（拉车的慢步）。要走快就提高步频，**不要加大幅度**：上段超过约 ±22° 时球节补不回腿长差，支撑蹄会离地。
（真马慢步步幅约 1.6 m，因为它的前肢摆动轴心在肩胛骨上部；这个木偶的轴心在肩关节，等效腿短，所以步幅偏短。远景看不出来；近景需要更大步幅就得加肩胛段，那是改骨架。）

## 刚体挽具的限制
- 颈圈挂在 `Body`：步态表里的点头（`Neck` X ±4°）和 `Horse_axes.png` 里的 `Neck` X +15° 都看不出颈穿出颈圈；低头吃草那种大角度没测，预计会穿。
- 挽绳残段、后鞦贴着躯干和大腿外侧走，是刚体：后腿大幅摆动时大腿外侧可能擦到它们（步态表幅度下的 `Horse_walk.png` 看不出）。
- 眼罩、衔铁在 `Head` 下，跟头一起动，没有限制。

# 驿站马车（Stagecoach）

由 `tools/blender/build_coach.py` 生成 `Game/Assets/_MercyCreek/Art/Vehicles/Stagecoach.gltf`，约 33k 三角面。康科德式：蛋形车厢吊在两条皮吊带上，褪色红漆 + 赭黄装饰条 + 金字"MERCY CREEK"（Rye，SIL OFL），黄色走行部，铁箍木轮，车顶行李栏 + 行李，后行李舱，车夫座 + 斜脚踏板 + 刹车杆 + 车灯，双马辕杆 + 平衡横木 + 单马横木 + 颈轭 + 接到马身上的挽绳。
导入约定同上：车头朝 Unity +Z，根节点不用转，原点在两轴中点正下方的地面。

## 节点（代码按名字查找）
`Stagecoach` → `Chassis`（走行部 + 辕杆 + 横木 + 挽绳 + 皮吊带）→ `Wheel_FL` / `Wheel_FR` / `Wheel_RL` / `Wheel_RR`、`Body` → `Door_L` / `Door_R`、`DriverSeat`；
`Stagecoach` → `PassengerExit_L`、`Hitch_L`、`Hitch_R`（空节点）。静止时所有 localRotation 都是单位旋转。

## 怎么动
- **车轮**：绕局部 **X**，**正角 = 向前滚**（车顶点往 +Z 走）。角度（度）= 行驶距离 / 半径 × 57.3；前后轮半径不同，要分别算。
- **车门**：`Door_L` 绕局部 **Y 负**方向开（门的前缘向 -X 外摆），`Door_R` 绕 **Y 正**。开到 75–90° 不碰后轮。`Reviews/blender/Stagecoach_door.png` 是 `Door_L` 开 75° + 车厢摇摆的测试。
- **车厢摇摆**：`Body` 绕 X = 前后俯仰（正 = 车头往下），绕 Z = 左右侧摆；行驶中 ±2–3°、慢周期（0.6–1 Hz）最像吊带车。车夫、车门、行李、后舱都挂在 Body 下一起摇。
- **马**：`Horse` 根节点放在 `Hitch_L` / `Hitch_R`（同位置、同朝向）。马车往前走多少，马的根也往前走多少；行走用上面的步态表。马身上的挽绳残段末端和车上的挽绳末端在静止站立时对齐（行走时马有 2–5 cm 起伏，接头处会有小错位，远景看不出）。
- **车夫**：`Mannequin_Driver` 根节点放在 `DriverSeat`（无旋转），坐姿：`L_/R_UpperLeg` X -80（Z ∓4 微分腿），`L_/R_LowerLeg` X +60，`Spine` X +6，`Chest` X +4，`L_UpperArm` X -38 Z -8，`R_UpperArm` X -34 Z +8，`L_/R_LowerArm` X -52 / -56，`L_/R_Hand` X -10，握缰：`L_Fingers` Z +60、`L_FingersTip` Z +50、`R_*` 取反。这样屁股落在坐垫上，鞋底正好踩在斜脚踏板上（脚踏板就是按这个姿势的鞋底平面做的）。见 `Reviews/blender/Stagecoach_driver.png`。
- 乘客下车：左门开 → 人偶从车厢内（门口 (-0.55, 1.03, 0)，地板高 1.03）经门下踏板落到 `PassengerExit_L`。
