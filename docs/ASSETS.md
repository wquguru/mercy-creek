## 音频（程序合成）
全部由 `tools/audio/` 里的 Python（numpy + scipy）从零合成：没有下载的采样、没有音色库。`tools/build_audio.sh` 用固定随机种子重建，结果逐字节相同；`tools/build_audio.sh --review` 另出波形 / 频谱图到 `Reviews/audio/` 并检查电平、循环接缝和华尔兹错音对齐。输出 48 kHz / 16-bit 到 `Game/Assets/_MercyCreek/Audio/`。

| 文件 | 生成脚本 | 授权 | 说明 |
|---|---|---|---|
| amb_saloon_loop.wav | tools/audio/sfx.py `amb_saloon_loop` | 自制 | 立体声 60 s 无缝循环；室内底噪 + 墙外闷住的风 + 偶尔的木头吱呀；RMS -30 dBFS |
| amb_wind_loop.wav | tools/audio/sfx.py `amb_wind_loop` | 自制 | 立体声 30 s 无缝循环；阵风（STFT 域时变带通）+ 低频隆隆 + 微弱风哨；RMS -30 dBFS |
| step_wood_01..06.wav | tools/audio/sfx.py `footstep` | 自制 | 旧木地板上的靴跟 + 前掌，01/04 带一点板子吱声；峰值 -6 dBFS |
| clock_tick.wav / clock_tock.wav | tools/audio/sfx.py `clock_tick` | 自制 | 落地钟擒纵"嗒"，tock 音高低约 14% |
| door_open.wav / door_close.wav | tools/audio/sfx.py `door_open` / `door_close` | 自制 | 厚木门 + 吱呀合页（粘-滑摩擦激励模态共振）；关门有门板低频撞击和门闩 |
| glass_clink.wav | tools/audio/sfx.py `glass_clink` | 自制 | 两只玻璃杯相碰（成对近频模态，有拍频） |
| glass_pour.wav | tools/audio/sfx.py `glass_pour` | 自制 | 约 2 s 倒威士忌：液柱噪声（共振随装满上升）+ 气泡 + 末尾一滴 |
| bottle_set.wav | tools/audio/sfx.py `bottle_set` | 自制 | 玻璃瓶放在木吧台上 |
| ui_remember.wav | tools/audio/sfx.py `ui_remember` | 自制 | "记住了"：倒放混响吸气 + 带小三度的钟声，约 2.4 s |
| ui_denied.wav / ui_click.wav | tools/audio/sfx.py `ui_denied` / `ui_click` | 自制 | 闷声"咚"（记不住更多）/ 很轻的界面点击 |
| reset_sting.wav | tools/audio/sfx.py `reset_sting` | 自制 | 重置：钢琴主和弦"磁带停转" + 上升噪声涌起，2.25 s 处硬切成低沉的轰，3.4 s 后归于寂静 |
| typewriter_key_01..04.wav, typewriter_bell.wav, typewriter_return.wav | tools/audio/sfx.py `typewriter_*` | 自制 | 4 号房的打字机：按键 / 行尾铃 / 回车 |
