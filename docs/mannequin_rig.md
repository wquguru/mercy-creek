# 木头人偶骨架（Mannequin rig）

由 `tools/blender/build_mannequin.py` 生成，输出 `Game/Assets/_MercyCreek/Art/Characters/Mannequin_{Gus,Professor,Crane,Nell,Driver,Townsman,Townswoman}.gltf`（+ .bin，贴图在共用的 `Art/Textures/`）。
街上的群演（`--lineup-town` 出合影 `Reviews/blender/Mannequin_TownLineup.png`）：
- **Driver**（车夫）：男骨架；带短披肩的长风衣（深褐）、平顶宽檐帽、红领巾、浅黄皮长手套（`Cloth_*_Glove*`，跟着手掌 / 四指两节 / 拇指各自弯）、高筒靴。主要用法是坐在马车 `DriverSeat` 上，坐姿见 `docs/horse_rig.md` 的"驿站马车"一节（UpperLeg X -80、LowerLeg X +60）；坐下时风衣后摆落进座位 / 前舱里看不见，前摆的两片从座位前沿垂下。
- **Townsman**（镇民男）：男骨架；卷袖工装衬衫、皮背带（`Cloth_Suspender_*`）、帆布裤、短靴、软毡帽。
- **Townswoman**（镇民女）：**女骨架（同内尔，关节坐标用表里"内尔"那一列）**；长袖连衣长裙（`Cloth_Skirt` 挂在 Hips，同内尔的走路限制）、披肩（`Cloth_Shawl` + 后背三角 `Cloth_Shawl_Point`）、遮阳软帽（`Cloth_Bonnet`）。
**没有蒙皮、没有骨骼**：每一段身体是一个独立网格对象，层级就是骨架。转一个节点的 `localRotation`，它和它下面的所有段（连同挂在上面的衣服）一起转。

## 导入约定
- glTFast 直接导入，**根节点不需要转 180°**（和 Saloon.glb 不同）。导入后角色面朝 Unity **+Z**，Y 向上，1 单位 = 1 米。
- 在 Blender 里角色面朝 **-Y**（Blender 前视图看到的是正面）。Unity (x, y, z) = Blender (-x, z, -y)。
- 根节点 `Mannequin` 在地面、两脚之间（原点 = 落地中心）。`Hips` 是它唯一的身体子节点。
- **L = 角色自己的左边 = Unity -X**（面朝 +Z 时的左手边）。
- 每个关节节点的**原点就在关节转轴上**，**静止姿势下所有 localRotation 都是单位旋转**（导出前已核对 GLB：没有任何节点带 rotation）。静止姿势不是 T-pose：双臂自然下垂、各向外展 8°，腿垂直。
- 所以每个节点的局部轴在静止时 = 角色轴：+X 角色右手边，+Y 上，+Z 前。动画直接写"相对静止"的旋转即可。

## 节点名（代码按名字查找）
`Mannequin` → `Hips` → `Spine` → `Chest` → `Neck` → `Head`；`Chest` → `L_/R_UpperArm` → `L_/R_LowerArm` → `L_/R_Hand` → `L_/R_Fingers` → `L_/R_FingersTip`，`L_/R_Hand` → `L_/R_Thumb`；`Hips` → `L_/R_UpperLeg` → `L_/R_LowerLeg` → `L_/R_Foot`。
- `L_/R_FingersTip` 是额外的第二节手指（四指远节），挂在 `Fingers` 下，弯两节才握得住杯子 / 弹琴。不用可以忽略。
- 四根手指在同一个节点里一起弯（连指手套式），拇指单独一节。
- 服装是 `Cloth_*` 子节点（例如 `Cloth_Apron`、`Cloth_Coat_Torso`、`Cloth_L_Sleeve_Upper`、`Cloth_BowlerHat`），原点同样在所属关节，localPosition = 0。要换装 / 摘帽子就开关这些节点。

## 旋转方向（Unity `Quaternion.AngleAxis`，作用在 localRotation 上）
| 动作 | 节点 | 轴 | 正负 |
|---|---|---|---|
| 抬腿向前（屈髋） | `*_UpperLeg` | X | **负** |
| 屈膝（小腿往后） | `*_LowerLeg` | X | **正** |
| 勾脚尖（背屈） / 绷脚 | `*_Foot` | X | 负 / 正 |
| 手臂向前抬 | `*_UpperArm` | X | **负** |
| 屈肘（前臂向前 / 向上） | `*_LowerArm` | X | **负** |
| 手臂向外侧张开 | `L_UpperArm` / `R_UpperArm` | Z | L 负 / R 正 |
| 握拳（四指向掌心弯） | `L_Fingers`、`L_FingersTip` / `R_*` | Z | L 正 / R 负 |
| 拇指向掌心收 | `L_Thumb` / `R_Thumb` | Z | L 正 / R 负 |
| 弯腰 / 低头（向前） | `Spine`、`Chest`、`Neck`、`Head` | X | **正** |
| 转头向角色左边 | `Head`（或 `Neck`） | Y | **负** |
| 侧弯向角色左边 | `Spine` / `Chest` | Z | 正 |

（换算：Blender 里绕 X 转 θ = Unity 绕 X 转 θ；Blender 绕 Y = Unity 绕 Z 同号；Blender 绕 Z = Unity 绕 Y 反号。）
手掌静止时朝向身体内侧（左手掌心朝 +X，右手掌心朝 -X），拇指在前侧（+Z）。手臂向前抬到水平时手掌相对，适合端杯；再绕前臂轴（`*_LowerArm` 的局部 Y）转 ±90° 掌心朝下，适合弹琴。

## 刚性衣服的限制
- 衣服是挂在各段上的刚体壳。躯干衣服按统一外形切成 胸 / 腹 / 臀 三段并互相重叠，弯腰 ±20° 内看不到缝。
- 袖子、裤腿在肘 / 膝处有重叠，屈肘 / 屈膝 ≤ 110° 基本不穿；更大角度会在关节内侧互相插入（木偶本身也会）。
- **长裙（内尔）**、**围裙（格斯、内尔）**挂在 `Hips` 上，不跟腿动：走路步幅建议髋部摆动 ≤ ±20°，否则大腿会顶出裙子 / 围裙。内尔是玩家，第一人称看不到，镜子里只需站姿 / 小步。
- **风衣下摆（克兰）**前面是开口的，腿从开口摆出，步幅 ±30° 也可；坐下时下摆后片会插进椅面（坐姿时可以把 `Cloth_Coat_Tail` 往后转一点或接受）。
- 教授坐琴凳弹琴（屈髋 90°、屈膝 90°）不会穿帮：他只穿长裤和马甲。
