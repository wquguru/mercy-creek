# 自主决定记录

人不在场时代理做的设计取舍。每条：日期 · 决定 · 理由 · 可替代方案。人复核后在条目后标"已确认"或改掉。

## 2026-10-15 · 生成产物不进 Git
- 决定：Saloon.glb（230MB）、.blend、HDRI 副本、构建、评审截图不提交，由 `tools/bootstrap.sh` 重建
- 理由：GitHub 免费 LFS 配额有限；这些都能由脚本 + CC0 源重新生成
- 替代：买 LFS 数据包后全部提交

## 2026-10-15 · 剧本由代理起草
- 决定：按 `GAME_DESIGN.md` 的版本实现——女招待内尔、酒保格斯、钢琴师教授、陌生人克兰；"作者在重写这个下午"的设定；错音拼出 CAGE；10 个碎片；重置 / 出逃 / 觉醒 3 个结局
- 理由：用户授权全自主完成；不设这条剧本就没法做 NPC 和对话
- 替代：人改写剧本后，只需改 `Story.cs` 和文本表

## 2026-10-15 · NPC 是木头人偶
- 决定：所有 NPC（和玩家自己的手）是关节木头人偶，戴帽子、围裙、风衣等简单服装；由 Blender 脚本建模，分段刚体挂在关节上，Unity 里用代码驱动走路 / 待机 / 手势 / 看向
- 理由：（1）剧情上"作者还没画脸"，人偶本身就是第一个线索；（2）没有 Tripo Key，CC0 写实人体 + 动捕重定向的链路风险大、容易恐怖谷；（3）刚体分段没有蒙皮穿模问题，AI 可以完全脚本化
- 替代：拿到 Tripo / 写实角色后，把人偶换成真人模型，剧情里改为"镜子里才是人偶"

## 2026-10-15 · 音频全部用 Python 合成
- 决定：环境音、脚步、钟摆、钢琴曲等用 numpy 程序化合成；钢琴曲为原创华尔兹，用合成的老式走音钢琴音色
- 理由：Freesound 下载需登录且多数为 CC-BY；可用的钢琴音源多为 CC-BY；合成可完全掌控"错音"机制
- 替代：后期换录音或 CC0 采样

## 2026-10-15 · 华尔兹的调性与错音位置
- 决定：《Mercy Creek 华尔兹》用 F# 大调、3/4、112 BPM、36 小节（57.857 s）；错音放在 A' 段第 4 小节（V 和弦 C# 上三拍长的 G#4，24.11 s）。错音版本把这个音换成 C5 / A4 / G4 / E4（各取离 G#4 最近的八度）。同一处在 11.25 s 先弹对一次，让耳朵先记住"本来的样子"
- 理由：C# 大三和弦（C#–E#–G#）与 C、A、G、E 各差半音，四个错音都必然刺耳；半终止的长音最容易被注意到
- 替代：换调或换位置只需改 `tools/audio/piano.py` 的 `CHORDS / MELODY / SPOT_BAR / WRONG`，再同步 `docs/audio_waltz.md` 和游戏里的字幕时间

## 2026-10-15 · 钢琴 / 人偶 / 道具 / 街景全部脚本建模
- 决定：自动钢琴、4 个木头人偶、打字机等道具、窗外街景都用 Blender 脚本程序化建模（`tools/blender/build_{piano,mannequin,props,street}.py`），贴图只用 ambientCG CC0 + Pillow 生成的文字贴图（Rye，SIL OFL）。产物 GLB 和 Saloon.glb 一样不进 Git，由 `tools/bootstrap.sh` 重建（重建结果逐字节相同）
- 人偶：层级即骨架，每段原点在关节、静止旋转为单位、手臂下垂外展 8°；在要求的节点名之外多了 `L_/R_FingersTip`（四指第二节，握杯 / 弹琴用）；内尔加了一个深棕发髻，让无脸人偶在镜子里能认出是她；人偶木纹贴图 2K，其余 1K
- 衣服是刚性壳：长裙 / 围裙挂在 Hips 上，步幅大了会被腿顶穿（限制写在 `docs/mannequin_rig.md`）
- 没做 Mirror.glb：酒馆已用 Poly Haven `ornate_mirror_01`
- 理由：没有 Tripo Key；全脚本可复现、授权干净；木偶风格本身是剧情线索
- 替代：拿到 Tripo / 写实角色后替换；衣服改成蒙皮布料

## 2026-10-15 · v2：从酒馆扩展到一条街（用户要求"扩展到小镇，分多个场景"）
- 决定：做"一条街"而不是整座镇——酒馆 + 主街（两侧 9 栋房子）+ 电报局室内 + 教堂墓地 + 西头画布。"多个场景"按**游戏里的地点**理解，按稿数逐步解锁（第 1 稿只有酒馆，第 2 稿街道和电报局，第 3 稿墓地）；Unity 里仍是**一个场景**，由 `SetupSaloon` + `SetupTown` 分区生成
- 理由：（1）每轮要整份重载世界、NPC 要从街上走进酒馆，一个场景最简单可靠；多场景叠加会让跨场景引用、APV 烘焙、重载都变复杂；（2）"作者每一稿多写一点"让扩图本身成为剧情；（3）Web 包体和工期可控
- 替代：真正拆成多个 Unity 场景叠加加载（Bootstrap + 各地点），或继续往外扩（马房、旅馆室内）
## 2026-10-15 · 易懂性改造
- 决定：稿数 = 轮数 + 11（第一轮就是"第 12 稿"，玛莎是第 11 稿的人）；开场黑底打字页；每次重置打出"第 N 稿 —— 作废 / 第 N+1 稿"；Tab 记忆本给"下一步"提示；乐谱上圈出错音；镜子独白点明"大家都没有脸"；第 1 稿结尾明说"记住点什么，带到下一稿"；暂停菜单"结束这个下午"
- 理由：用户反馈"玩家不是很好懂"；原版要到 4 号房才可能意识到"被写出来"
- 替代：更隐晦（删提示，只留记忆本列表）
## 2026-10-15 · 马车、马、镇民都是木头人偶风格
- 决定：驿站马车写实建模（Blender 脚本），马是关节木头人偶马（和人偶同一套语言），镇民 3 个定格群演（第 3 稿起转头看你，第 5 稿起转身）；马车从西头画布里驶出
- 理由：没有 CC0 写实马的动画链路；木头马与"作者还没画皮毛"一致，程序动画可控
- 替代：Quaternius CC0 动画马（卡通风，需要重做材质）
## 2026-10-15 · 一轮从 180 秒改为 240 秒；出逃改到画布
- 决定：街道让走路时间变长，循环拉到 240 秒；"出逃"从酒馆后门改成撕开西头画布（需要 door + calendar，第 2 稿起）；后门永远锁死
- 理由：画布是"世界只写到这里"最直观的表达
- 替代：保留后门作为第二条出逃路线
## 2026-10-15 · 室外不放 APV 探针
- 决定：APV 只放在室内（酒馆、4 号房、电报局）；街上靠实时阳光 + 天空盒环境光 + 一个大反射探针
- 理由：室外探针会沿薄墙往室内漏光（v1 踩过的坑）；室外本来就以直射光和天光为主
- 替代：室外加粗密度 APV + 更强的漏光抑制

## 2026-10-16 · 试玩录像用离线取景（Recorder.cs）
- 决定：新增 `-record <目录>`，和 `-playbot` 一起用：`Time.captureFramerate = 30` 逐帧截 JPG，游戏声音用 `AudioRenderer` 离线渲染（录制时扬声器静音），`frames.tsv` 记每帧的稿数、本轮时间、倍速和屏幕字幕，剪辑时据此挑段、去掉 PlayBot 干等时的 ×4 快进段
- 理由：要给介绍视频配试玩解说；本机终端没有屏幕录制权限，而且录屏在渲染慢时会掉帧，离线取景画面稳定、可重拍
- 替代：手动录屏（QuickTime / OBS）

## 2026-10-16 · 发布预告片 v2（tools/trailer/）
- 决定：重做预告片为约 85 秒三幕结构：开场打字"1882 年 6 月 14 日，下午三点" → 钟声与华尔兹（外景时闷、进门打开），格斯同一机位说两遍同一句话 → 错音后磁带停转、画面同步减速褪色 → 第二幕一秒一下的心跳，华尔兹开头动机放慢成"一镜一音"、最后一个音弹成错音 → 第三幕钟摆加速 + 稿数闪现，在 66 秒一刀切成静默 → 打字机"……她终于醒了" → 黄昏门脸上的片名与结局曲。2.39:1 黑边、轻胶片颗粒，旁白和台词都放在下黑边里（亮的外景上更易读）；英文片名用 IM Fell English SC（OFL），中文用思源宋体
- 理由：旧版是 8 个镜头首尾淡入淡出 + 一首曲子，没有节奏和叙事；新版的每个剪辑点都落在小节线或心跳上，"错音"既是声音线索也是剪辑的转折点。素材全部来自游戏实机（Trailer.cs 逐帧离线取景，2 倍超采样）和项目自己的合成音频，不涉及外部授权
- 替代：英文版（把 edl.py 的 TEXTS 换成英文即可）；竖屏 / 方形社交版（2.39:1 构图裁成竖屏损失太多，需要单独取景）
- 补充（同日）：X 用竖版海报 4:5（1080×1350，X 时间线里不裁切的最高比例），由 `tools/trailer/poster.py` 生成。画面不从横版裁（只剩 864 宽），而是用竖版窗口重拍 void 镜头（`-trailer <目录> -shot void -screen-width 1080 -screen-height 1350`），取第 60 帧：纸墙上撕开的口子里是整条小镇，最直接地说出“世界是画出来的”。替代：打字机特写（typewriter 镜头）或黄昏马车（dusk），后者招牌上已有 MERCY CREEK 字样，与片名重复
- 补充（同日）：片子从黑场打字开场，社交平台拿第一帧当缩略图会是纯黑。分享版（`_share.mp4`）开头加 0.6 秒封面（76.5 秒的片名帧）再淡到黑，声音整体后移 0.6 秒；母版不动。两版都内嵌封面图（attached_pic）。替代：只内嵌封面不加开头（X / 微信不认内嵌封面）；把开场黑底换成压暗的黄昏画面（会改掉开场的字卡设计）

## 2026-10-16 · 深度打磨：布料蒙皮、镜子反射、手持道具（用户授权全自主完成）
- 决定：长裙 / 围裙 / 风衣后摆不改 Blender 管线，而是在 Unity 场景生成时把这几件网格复制成蒙皮网格，权重按顶点高度和左右位置程序生成，骨骼直接用人偶现有关节节点
- 理由：人偶"层级即骨架"的约定、所有动画代码都不用动；只有挂在 Hips 上垂到腿部的布料会穿模，局部改最小。替代：在 Blender 里建 Armature 导出 glTF skin（要重写人偶管线和 MannequinRig 的节点查找）；布料模拟（成本高、Web 端不稳）
- 决定：镜子做真实平面反射，镜中站内尔的木头人偶（玩家第一人称没身体，镜中人偶就是"镜中人偶"碎片本身的画面）；第 4 稿起倒影慢 0.45 秒（GAME_DESIGN 第 4 轮"倒影慢半拍"原来只有文字）。看镜子时人偶抬右手
- 理由：剧情里点明"被写出来"最关键的一刻。只在近处、可见时渲染，半分辨率，平时零开销。替代：只放静态人偶贴图（不跟玩家动，破绽大）
- 决定：手持道具用 Unity 基本体拼（瓶、杯、布、笔），复用酒馆里已有的 Poly Haven 材质；不进 Blender 管线
- 理由：尺寸小、镜头远，基本体就够；和人偶"还没画完"的风格一致。替代：Blender 脚本建模，精度更高
- 决定：英文文本整体润色（39 条），"Draft N" 统一首字母大写；"saloon girl" 改为 "who serves at the saloon"（避免歧义）；"Talk to The Professor" 在句中改小写 the
- 决定：新增 Windows 64 位构建（Mono），只构建、未在真机运行，见 TECH.md

## 2026-10-16 · 收紧节奏 + 第 4 个结局"真相"（GAME_DESIGN v3）
- 决定：4 号房门改为"≥ 5 个碎片且有 `letter`"才开（原来任意 4 个）；出逃改为第 3 稿起（原来第 2 稿）；新增"真相"结局：4 号房已开且记住 `letter`、`cage`、`telegram`、`grave` 时，打字机停下等人，选"坐下来，自己打下一句"，黑场上由玩家打出"这一稿不再重写……教堂的钟第一次敲响了四下"
- 理由：PlayBot 实测觉醒第 4 稿 / 约 8 分钟、出逃第 3 稿 / 约 2 分钟就能通关，远低于 25–35 分钟目标，且能跳过信、错音、笔记本等核心揭示。让"自己的信"成为觉醒的钥匙（信上本来就写着"去四号房"），并把错音 / 电报 / 墓碑三条暗线收成一个更深的结局，最短路线变成出逃 3 稿、觉醒 5 稿、真相 6 稿。真相不强制，觉醒仍是正常结局
- 决定：钟敲四下用新合成的 `church_bell_four`（与 `church_bell_three` 同一套算法）；真相结局的音乐等钟声敲完再起
- 替代：觉醒要求固定的 5 个碎片（更硬、更像清单）；把真相做成觉醒后的二周目内容；保留 4 个碎片门槛、只加真相（节奏问题不解决）
- 补充（同日）：英文字幕版预告片（`TRAILER_LANG=en` / `make_trailer.sh --en`）：时间点、画面、配乐与中文版完全相同，只换 `edl.TEXTS_EN` 与片尾卡；台词与游戏内英文一致，稿数闪现用 "DRAFT 13"；打字机逐字间隔减半，整句用时和中文相近；拉丁字母字距收到中文的 0.2 倍。片尾平台仍写 "macOS · Web"（Windows 版未在真机验证）。母带限幅从 0.8 降到 0.74：AAC 编码过冲让成片峰值到了 -0.8 dBFS，现在 -2.2 dBFS
