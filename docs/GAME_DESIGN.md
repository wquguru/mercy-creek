# Mercy Creek — 游戏设计

> 状态：M2 剧本初稿（2026-10-15，代理自主撰写，见 `DECISIONS.md`）。代码以本文件为准；改剧情先改这里。

## 钩子
你是 Mercy Creek 酒馆的女招待内尔。每天下午三点，钢琴响起同一首曲子，同一个陌生人推门进来，然后一切重来。
**第几次循环，你才会醒来？**

## 世界观（玩家最后才知道）
Mercy Creek 是一个"作者"正在写的故事。每次循环是一**稿**：作者重写这个下午，想让它"写对"。
- 酒馆里的人是**木头人偶**——作者还没给他们画脸。只有内尔自己意识不到这一点（她照镜子看到的是人偶，这是一个碎片）
- 陌生人**克兰**是作者放进故事里的"读者"：他来检查这一稿，在笔记本里记下哪里不对
- 钢琴师"教授"是唯一隐约记得前几稿的人，他每一稿故意弹错一个音，留给内尔线索：错音依次是 **C、A、G、E**（cage，笼子）
- 楼上 4 号房是作者的书桌：一台打字机，正在打出内尔此刻的动作

## 核心规则
- 一轮 = 一个下午 = **180 秒**。时间到、或玩家主动在吧台后的床铺"睡去"，世界重置
- 世界全部复原，**只有玩家保留记忆碎片**；每轮只能记住 **1 个**新碎片（拾起第二个时提示"这一轮记不住更多了"）
- 碎片会解锁：新的对话选项、新的可交互物、终局门
- 首轮 30 秒内必出现第一个"不对劲"：酒保说"今天会是个好日子，内尔。"然后**同一句话再说一遍**，一字不差
- 完整通关目标：5–7 轮，约 15–20 分钟

## 角色
| 角色 | 外观 | 位置 / 日程 | 作用 |
|---|---|---|---|
| **内尔**（玩家） | 第一人称，看得到自己的木头手 | 出生在吧台后 | 觉醒者 |
| **格斯**（酒保） | 人偶，围裙、袖箍、八字胡贴片 | 一直在吧台后，擦杯子 / 倒酒 | 守旧者，台词固定，第 2 轮起出现口误 |
| **教授**（钢琴师） | 人偶，圆顶礼帽、马甲 | 坐在自动钢琴前 | 记录者，每轮错一个音 |
| **克兰**（陌生人） | 人偶，长风衣、宽檐帽、靴子沾土 | 60 秒进门 → 吧台 → 角落桌写笔记 → 160 秒上楼进 4 号房 | 读者 / 观察者 |

## 每轮时间表（基础）
| 时间 | 事件 |
|---|---|
| 0s | 内尔在吧台后，手里一只有缺口的杯子 |
| 3s | 教授开始弹《Mercy Creek 华尔兹》（原创，循环约 60 秒，弹 3 遍） |
| 12s | 格斯："今天会是个好日子，内尔。" |
| 18s | 格斯（一模一样）："今天会是个好日子，内尔。" |
| 60s | 前门打开，克兰进门，走到吧台，要威士忌（格斯倒酒） |
| 85s | 克兰端酒走到角落桌坐下，打开笔记本写字 |
| 130s | 克兰抬头看座钟："钟又停在三点了。" |
| 160s | 克兰起身上楼，进 4 号房，门关上（锁上） |
| 168s | 光线变红，内心独白："你突然很想记住点什么。" |
| 180s | 重置 |

## 随轮数变化
| 轮 | 变化 |
|---|---|
| 1 | 基础时间表 |
| 2 | 格斯第二句改成"今天会是个好日子，玛莎——内尔。"（口误：上一稿的名字） |
| 3 | 克兰进门时停顿一下，看了内尔一眼 |
| 4 | 克兰提前到 45 秒进门；镜子里的倒影慢半拍 |
| 5+ | 克兰坐下前对内尔说："你比上一稿醒得早。" |
| 任意 | 教授的错音：第 1 轮 C、第 2 轮 A、第 3 轮 G、第 4 轮及以后 E |

## 记忆碎片（10 个）
每个碎片：物件或人 → 第一次看到的文字 → 记住后再看的文字。

| id | 在哪 | 触发条件 | 内容（摘要） |
|---|---|---|---|
| `clock` | 落地钟 | — | 钟停在三点。钟摆在动，指针不动 |
| `mirror` | 楼梯旁镜子 | — | 镜子里是一个没有脸的木头人偶，穿着你的围裙 |
| `piano` | 教授 / 钢琴 | 听完一遍曲子后与教授对话 | 他每次弹到同一处都错一个音，这一稿错的是 {note} |
| `door` | 前门 | — | 门外的街道一动不动，像画在布上 |
| `glass` | 吧台上的杯子 | — | 你擦的杯子缺口永远在同一个位置，哪怕你换了一只 |
| `name` | 格斯 | 第 2 轮起，听到口误后对话 | 他叫过你"玛莎"。玛莎是谁？ |
| `notebook` | 克兰的笔记本 | 克兰坐下后对话，或他离开桌子后看桌上 | 笔记本上写着你接下来要说的话 |
| `calendar` | 吧台后墙上的日历 | — | 每一页都是 1882 年 6 月 14 日 |
| `letter` | 吧台抽屉 | 需要已记住 `glass` | 一封给你的信，笔迹是你自己的："别信钟。去 4 号房。" |
| `cage` | 教授 | 已记住 `piano` 且至少过了 3 轮 | 错音连起来是 C、A、G、E |

## 对话
- 走近 NPC，准星对准按 E，弹出最多 3 个选项；选项随已记住的碎片解锁
- NPC 说话时会转头看玩家；对话期间时间照常流逝（循环不暂停）
- 关键选项：
  - 克兰 + 已记 `notebook`："你在写我。" → 克兰："不。我在读你。"（第 5 轮起也可解锁）
  - 克兰 + 任意 ≥1 碎片："这里一切都很好。" → **重置结局**
  - 教授 + `piano`："你是故意弹错的。" → 教授："总得有人记住些什么。"
  - 格斯 + `name`："玛莎是谁？" → 格斯停顿，重复："今天会是个好日子，内尔。"

## 结局（3 个）
| 结局 | 触发 | 演出 |
|---|---|---|
| **重置** | 对克兰说"这里一切都很好" | 克兰合上笔记本："那就照这样写。"画面淡出，碎片全部清空，结局卡"重置——你选择了留下" |
| **出逃** | 已记 `door` + `calendar` 后，厨房后门出现可交互的门闩 | 推门出去：门外是没有渲染的灰色虚空和网格地面，走几步后结局卡"出逃——世界只写到这里" |
| **觉醒** | 已记任意 4 个碎片，4 号房门可开 | 房里一张书桌、一台打字机正在自己打字，纸上是"内尔推开了 4 号房的门……"；看纸 → 结局卡"觉醒——第 N 稿，你在 X 分 Y 秒后醒来" |

## 分享卡片
结局后生成一张 1200×630 的卡片：结局名 + 徽记、第几稿（轮数）、总用时、记住的碎片图标。按钮"保存图片"（Mac 存到桌面，Web 下载 PNG）。

## 界面
- 标题画面：酒馆远景慢推镜头，"开始 / 继续 / 设置 / 退出"
- 设置：鼠标灵敏度、主音量、音乐音量、语言（中 / 英）
- 暂停：Esc
- 自动存档：每轮开始时保存轮数与碎片；结局后清档
