# Mercy Creek — 游戏设计

> 状态：**v2（2026-10-15）**，代理自主撰写（见 `DECISIONS.md`）。在 v1（只有酒馆）的基础上：世界扩展到一条街；加上"第 N 稿"框架、开场打字页、记忆本，让玩家看得懂。
> 实现：`Scripts/Runtime/Story.cs`（时间表 / 碎片 / 对话 / 结局）+ `Loc.cs`（中英文本）。改剧情先改这里，再改这两个文件。

## 钩子
你是 Mercy Creek 酒馆的女招待内尔。每天下午三点，教堂敲三下钟，钢琴响起同一首曲子，同一辆驿站马车把同一个陌生人送到门口，然后一切重来。
**第几稿，你才会醒来？**

## 世界观（玩家逐步拼出来）
Mercy Creek 是一个"作者"正在写的小说。每次循环是一**稿**：作者重写这个下午，想把它"写对"。
- 酒馆里、街上的人都是**木头人偶**——作者还没给他们画脸。内尔自己也是（照镜子才发现）
- **陌生人克兰是"读者"**：作者派他来检查每一稿。他的笔记本上写着内尔下一步要做的事；电报局收到的电报是作者发给他的
- **钢琴师"教授"**隐约记得前几稿，每稿故意弹错一个音：C、A、G、E（cage，笼子）
- 上一稿里女招待叫**玛莎**。她被"删掉"了——教堂墓地里有她的墓碑，旁边还有一块没刻字的空白墓碑
- **世界只写到这里**：第 1 稿只有酒馆，门外的街像画在布上；之后每一稿，作者多写一点——街道、电报局、教堂。街道西头是一块巨大的画布，上面画着"后来的路"
- 楼上 4 号房是作者的书桌：一台打字机，正在打出内尔此刻的动作

## 稿数
- 玩家看到的是"**第 N 稿**"，N = 循环轮数 + 11（第一轮就是第 12 稿；玛莎是第 11 稿的人）
- 开场（点"开始"后）：黑底打字页，逐字打出，打字机声，可按任意键跳过：
  > MERCY CREEK · 第 12 稿
  > 1882 年 6 月 14 日，下午三点。
  > 酒馆女招待内尔站在吧台后，手里是那只有缺口的杯子。
  > 她不知道，这个下午已经写过十一遍了。
- 每次重置：黑场上打出"第 12 稿 —— 作废"，再打出"第 13 稿"，然后淡入

## 核心规则
- 一轮 = 一个下午 = **240 秒**（小镇比酒馆大，v1 是 180 秒）
- 世界全部复原，只有玩家保留**记忆碎片**；每轮只能记住 **1 个**新碎片
- **Tab 打开记忆本**：已记住的碎片（名字 + 一句话）、这个下午还剩多久、一条"下一步"提示
- 暂停菜单可以"**结束这个下午**"（直接进入下一稿，省得干等）
- 首轮 30 秒内必出现第一个"不对劲"：格斯把"今天会是个好日子，内尔。"一字不差地说两遍
- 第 1 稿结束前（光线变红时）明确告诉玩家规则："这个下午快结束了。你得记住点什么，带到下一稿。"
- 完整通关目标：6–8 稿，约 25–35 分钟

## 地点（每稿解锁）
| 稿（轮） | 写出来的地方 | 表现 |
|---|---|---|
| 第 12 稿（1） | 只有酒馆 | 前门推不开："门外的街道一动不动，像画在布上"；窗外的街静止、没有人和马车，只听得到马蹄声 |
| 第 13 稿（2） | **主街** + **电报局** | 开场独白："门外传来马蹄声。街道……好像被写出来了。"前门可以出去。别的店门上钉着纸条"待写" |
| 第 14 稿（3）起 | **教堂墓地** | 墓地栅栏门打开（第 2 轮时门上挂着"待写"）。街上的人偶开始转头看你 |

### 主街布局（Blender 坐标，Unity (x, y, z) = Blender (x, z, y)）
- 街沿 X 方向（东西），土路 y ∈ [-12.2, -2.4]；酒馆在北侧 x ∈ [-7, 7]，正门在 (0, 0)
- 北侧（酒馆这一排，门脸朝 -Y、在 y = 0）：西边**电报局**（可进，x ∈ [-15.5, -9]）、再往西一间待写的殡仪馆；东边**治安官办公室**（待写，x ∈ [9, 15]）、**澡堂**（待写，x ∈ [16.5, 23]）
- 南侧（对街，门脸在 y = -14）：已有的马房、杂货店、化验所、旅馆、理发店
- 东头：**教堂**（x ≈ 30–42，正面朝西，堵住街尽头），北侧是**墓地**（栅栏围起来，门朝街）
- 西头：**画布**（x = -34，垂直于街，12 m 高），画着"街道继续往西延伸进沙漠"；画布后面是格子纸虚空
- 玩家可走的范围：两侧栈道、街面、电报局室内、墓地；其余用隐形墙挡住

## 角色
| 角色 | 外观 | 位置 / 日程 | 作用 |
|---|---|---|---|
| **内尔**（玩家） | 第一人称 | 出生在吧台后 | 觉醒者 |
| **格斯**（酒保） | 人偶，围裙、袖箍 | 一直在吧台后，擦杯子 / 倒酒 | 守旧者，第 2 轮起叫错名字 |
| **教授**（钢琴师） | 人偶，圆顶礼帽、马甲 | 坐在自动钢琴前 | 记录者，每轮错一个音 |
| **克兰**（陌生人） | 人偶，长风衣、宽檐帽 | 坐驿站马车从画布里驶出 → 酒馆 → 角落桌写笔记 → 上楼进 4 号房 | 读者 |
| **车夫** | 人偶，坐在马车上 | 一动不动 | 群演 |
| **镇民 ×3** | 人偶 | 定格在街上：过马路走到一半、靠着拴马桩、坐在旅馆门口长椅上 | 群演；第 3 轮起转头看你，第 5 轮起跟着你转身 |
| **马 ×2** | 木头人偶马 | 拉驿站马车 | 也是"还没画皮毛"的木头 |

## 每轮时间表（240 秒）
| 时间 | 事件 |
|---|---|
| 0.5s | 第 1 稿：开场字幕"下午三点。你手里是那只有缺口的杯子。"；第 2 稿："门外传来马蹄声……街道好像被写出来了"；之后："……又是这个下午。" |
| 1s | 教堂钟敲三下（远处） |
| 3s | 教授开始弹《Mercy Creek 华尔兹》（约 58 秒一遍，循环） |
| 12s / 18s | 格斯："今天会是个好日子，内尔。"（第 2 轮起第二句口误成"玛莎——内尔"） |
| 27s | 第一个错音（每遍同一处） |
| 30s | 电报局的电报机开始自己咔哒作响（第 2 轮起） |
| e − 15s | 驿站马车从西头画布里驶出，沿街往东（第 1 轮只有马蹄声） |
| e | 马车停在酒馆门口，克兰下车走进酒馆（e = 65s；第 4 轮起 e = 50s） |
| e + 10s | 克兰在吧台要威士忌，格斯倒酒 |
| e + 25s | 克兰端酒走到窗边角落桌坐下，打开笔记本写字 |
| 150s | 克兰抬头看座钟："钟又停在三点了。" |
| 180s | 克兰起身上楼，进 4 号房，门关上 |
| 184s | 字幕：陌生人上了楼 |
| 228s | 光线变红（第 1 轮附带规则说明） |
| 240s | 重置 |

## 随轮数变化
| 轮 | 变化 |
|---|---|
| 1 | 只有酒馆；基础时间表 |
| 2 | 街道、电报局写出来；格斯口误"玛莎" |
| 3 | 墓地开放；克兰进门时停顿，看了内尔一眼；镇民转头看你 |
| 4 | 克兰提前 15 秒到；镜子里的倒影慢半拍 |
| 5+ | 克兰坐下前对内尔说："你比上一稿醒得早。"；镇民跟着你转身 |
| 任意 | 教授的错音：第 1 轮 C、第 2 轮 A、第 3 轮 G、第 4 轮及以后 E；钢琴上的乐谱圈出已经弹错过的音 |

## 对话
- 走近 NPC，准星对准按 E，弹出选项；选项随已记住的碎片解锁；对话期间时间照常流逝
- 关键选项：
  - 克兰 + `notebook`（或第 5 轮起）："你在写我。" → "不。我在读你。写你的人不在这里。"
  - 克兰 + `telegram`："谁给你发的电报？" → "写这个故事的人。他总觉得这个下午还不对。"
  - 克兰 + 任意 ≥1 碎片："这里一切都很好。" → **重置结局**
  - 教授 + `piano`："你是故意弹错的。"（第 4 轮起）→ 得到 `cage`
  - 格斯 + `name`："玛莎是谁？" → 格斯卡住，重复台词
  - 格斯 + `grave`："玛莎死了吗？" → "……没有谁死了，内尔。只是被划掉了。"

## 记忆本的"下一步"提示（按顺序取第一条成立的）
1. 还没记住任何东西："每个下午只能记住一件事。找找这里不对劲的地方。"
2. 已记 ≥ 4 个："你记得够多了。四号房的门在等你。"
3. 已记 `door` 和 `calendar`，第 2 轮起："连日子都是假的。去街道西头，撕开那块画布。"
4. 已记 `door`，没记 `calendar`："画布挡住了路。要是连时间也是假的……"
5. 第 2 轮起、没记 `door`："街道是真的吗？走到西头看看。"
6. 其余："记住四件事，四号房的门就会打开（{n}/4）。"

## 结局（3 个）
| 结局 | 触发 | 演出 |
|---|---|---|
| **重置** | 对克兰说"这里一切都很好" | 克兰合上笔记本："那就照这样写。"淡出，碎片全部清空，"重置——你选择了留下" |
| **出逃** | 已记 `door` + `calendar`，第 2 轮起，在西头画布按 E"撕开画布" | 画布裂开一道口子，后面是格子纸虚空；走进去，"出逃——世界只写到这里" |
| **觉醒** | 已记任意 4 个碎片，4 号房门可开 | 打字机在自己打字："……内尔推开了四号房的门。这是第 N 稿。她终于醒了。"；"觉醒——第 N 稿，你在 X 分 Y 秒后醒来" |
- 酒馆后门（v1 的出逃路线）保持锁死："门闩锈死了。"

## 界面
- 标题画面：酒馆远景慢推，"开始 / 继续 / 设置 / 退出"
- 设置：鼠标灵敏度、反转 Y、主音量、音乐音量、语言（中 / 英）
- 暂停（Esc）：继续 / 结束这个下午 / 设置 / 回到标题 / 退出
- 左上角："Mercy Creek · 第 N 稿" + "记忆 n · Tab 打开记忆本"
- 自动存档：每轮开始时保存轮数与碎片；结局后清档
