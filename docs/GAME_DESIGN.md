# Mercy Creek — 游戏设计（初稿，待定项标 TODO）

> **已实现（2026-10-14 原型）**：3 分钟循环与重置特效、4 个记忆碎片（钟 / 镜子 / 钢琴 / 前门）、每轮只记 1 个、二楼上锁门需 4 个碎片、"觉醒"结局卡。字幕是占位剧本，NPC 尚未制作。

## 钩子
你是 Mercy Creek 酒馆里的女招待。每天下午三点，同一个陌生人推门进来，同一首曲子响起，同样的事情发生——然后一切重来。
**第几次循环，你才会醒来？**

## 核心循环
- 一轮 = 游戏内一个下午 ≈ **3 分钟**现实时间，结束时（或玩家"死亡"时）重置
- 世界状态全部复原，**只有玩家保留"记忆碎片"**
- 每轮可以拾起 1 个碎片：一句不该知道的话、一个物件的异常、一个 NPC 的口误
- 碎片解锁新的对话选项与行动 → 下一轮能走更深
- 完整通关 15–20 分钟；首轮就能看到 1 个"不对劲"，保证前 30 秒有钩子

## 场景
- 主场景：Mercy Creek 酒馆（一层大厅 + 吧台 + 自动钢琴 + 楼梯 + 二楼走廊 + 1 个上锁房间）
- 窗外：大街远景（低精度 / 绘景），不可进入

## 角色（全部原创）
| 角色 | 原型 | 循环中的作用 |
|---|---|---|
| 玩家：女招待 TODO 名字 | 觉醒者 | 主视角 |
| 陌生人 | 外来者 / 观察者 | 每轮 3 点准时进门，触发事件 |
| 酒保 | 守旧者 | 台词永远一样，第 N 轮出现口误 |
| 钢琴师 | 记录者 | 曲子每轮细微变化（线索） |
| 楼上的房客 | 知情者 | 上锁房间，终局关键 |

## 结局（3 个）
1. **重置**：放弃追问，循环继续
2. **出逃**：推开酒馆后门——门外什么都没有渲染（元叙事：世界只做到这里）
3. **觉醒**：上锁房间里是"观察者"的终端；揭示小镇、你、以及这个游戏，都是 AI 写出来的
